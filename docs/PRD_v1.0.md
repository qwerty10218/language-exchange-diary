# PRD v1.0 — 言語交換日記

## 目標
一個兩人能透過網址閱讀的溫暖奶茶手帳網站；可記錄日韓語言交換學到的詞句與備註、立即搜尋或複習，並在手機描寫韓文字母與日文假名。

### 已確認
| 項目 | 規格 |
|---|---|
| 風格 | 奶茶手帳；柔和、簡單、閱讀舒服 |
| 使用方式 | 無登入、靜態部署、可分享連結 |
| 編輯 | 維護者在 repo 更新資料，網站訪客不編輯公開詞條 |
| 內容 | 兩份筆記：`ko` 朋友教我的韓文；`ja` 我教朋友的日文 |
| 記憶感 | 單字、例句、備註；不做聊天逐字紀錄或時間線 |
| 第一操作 | 查字及直接開始複習並列 |
| 聲音 | **授權明確、檢聽過的真人音檔**，無自動 TTS 取代 |
| 書寫 | 韓文 40 個字母；平假名 46、片假名 46；動畫、引導、判定 |
| 漢字 | 假名標註（振假名）、詞義與真人音檔；不做漢字筆順 |
| 完整度 | 充分測試後再發布；可分階段開發，但第一版應達驗收 |

## 主資訊架構（單頁或簡單分頁）
- **首頁**：網站名／語言切換；全域查詞；「開始複習」主操作；最近新增詞條（沒有個人日記資訊）。
- **詞庫**：日文／韓文兩獨立 Tab；原文、意思、讀音、個人記音、例句、備註、聲音（有才顯示播放）。
- **複習**：翻卡、看中文選原文、簡易拼字；題數 5／10／全部可選； localStorage 儲存每裝置的熟悉度。
- **文字練習**：語言選擇→字元表→字框；示範動畫→沿線描→獨立寫→筆畫回饋。
- **關於／資料來源**：語音與筆順來源及授權，公開網址提醒。

## 明確不做
帳號／密碼／Supabase／雲端資料庫／雙人編輯 UI／聊天匯入頁面／社交分享動態／積分排行榜／強制打卡／AI 自動評測口說／韓日漢字筆順／公開個人聊天原文。

## 不同裝置的行為
- 內容由專案發版更新：重新打開網站或重整後讀取新版 JSON。
- 各裝置複習進度獨立，清除瀏覽器資料即會消失；不宣稱跨裝置同步。
- 首頁與詞庫可在手機上快速切換；書寫框適合單指描寫，頁面其他區域可正常捲動。

## 品質判定與未完成項
- **發音**：需要經過人工來源核對；如果音檔未取得，顯示未收錄，不能標示為真人、不能靜默換 TTS。第一版欲宣稱完整真人發音，必須達到約定的核心詞條/字母覆蓋目標；目前素材尚未取得，這是上線阻礙。
- **筆順**：132 個基本字元的來源資料及動畫／描寫／判定必須逐項檢查。軌跡比對是一種教學回饋，不宣稱專業書法或官方筆跡認證。
- **隱私**：不含任何私人資訊的前提下才公開發布。

## 最小驗收故事
1. 我在 iPhone 打開網址，選「韓文」搜尋 `다이어트`，讀到「減肥」、備註與真人音檔（若已取得）。
2. 朋友在手機打開同網址，選「日文」找到 `美しい`，看見 `うつくしい` 並可聽錄音（若已取得）。
3. 兩人點「開始複習」後分別作答，各自裝置的進度不互相影響。
4. 在手機字框選 `ㅏ` 或 `あ`，觀看每筆動畫、沿路徑描寫，再自由描寫得到有說明的回饋。
5. 維護者把 ChatGPT 產出的 JSON 交給 Codex 檢查／匯入，部署後新詞在網站上可搜尋。
