## 已接上的入口與狀態

- 日文：單字表／五十音表／練習；韓文：單字表／韓文 40 音表／練習。手機的三個入口置於學習區上方並隨捲動固定。
- 字母表直接列出 46 平假名、46 片假名、19 子音及 21 母音；不受已學詞庫與搜尋影響。點字可查看讀音、羅馬拼音與書寫狀態。真人音訊未收錄，不顯示播放按鈕。
- 日韓兩個 Review 元件持續掛載，切換頁籤、語言或書寫入口均不重建正在進行的 session。已翻開的答案、題序、題目、記得數保留；手動「結束這次練習」才重設。整頁重新整理僅還原已答的 localStorage 進度，不還原未結束的題組。
- 一般書寫只列技術檢查通過的字元。開發模式 `#lab` 可測試含失敗字元的路徑，並查看完整 132 字 QA 預覽；production 不包含調校室。

- `ㅏ` 沿用 Phase 0 既有來源、中心線與 CC BY-SA 4.0 署名，未重新猜測。原始三字資料與 `src/stroke-engine.mjs` 未修改。
- 公開來源與授權入口：`public/strokes/catalog/index.html`；授權全文沿用 `public/strokes/sources/`。讀音參考為 [國際交流基金 Irodori](https://www.irodori.jpf.go.jp/en/resources.html) 及 [韓國國立國語院羅馬字規則](https://www.korean.go.kr/front_eng/roman/roman_01.do)，不複製該站音檔或圖表。
- `npm run writing:import -- --fetch`：維護者明確執行時取得固定版本 SVG，建立索引。已下載者使用本地副本；不在網站、build 或一般 check 中下載。`npm run writing:import` 只讀本地來源，不連網。
- `npm run writing:qa -- --write`：重算 QA 與類型，寫回專案索引及公開副本。正式內容須經檢查、使用者指示部署才會更新給朋友。
- `npm run writing:qa`：只驗證目前 QA 是否可重現、副本是否一致。缺資料與已封鎖失敗字元會列出，不代表整批 132 字可用；新增失敗若與索引記錄不同則檢查失敗。

## 集中設定與共用引擎

正式設定為 `data/writing-settings.json`；`src/writing-config.mjs` 合併全域、筆畫類型及有理由的少量字元覆寫。目前沒有字元覆寫。

- 起點 15%、磁吸半徑 13%、偏差 20%、完整描寫進度 75%、貼近比例 60%。
- 保留現有方向帶寫：起拉觸發 4% 字框，短筆最多取自身長度 15%；方向一致才補完。75% 供完整描寫判定使用，並不是現行短拉帶寫的觸發進度。
- 示範每筆 1500ms、接受動畫 450ms、參考線開啟；筆順嚴格、反向拒絕，不提供關閉控制。
- 直線／曲線使用既有局部搜尋上限 25%；短筆縮為 18%、自交或與其他筆畫相交者縮為 14%。類型自動依中心線曲線命令、長度與交叉判斷產生，沒有逐字複製判定器。
- 調校室可即時調整並複製／下載 JSON；不會由瀏覽器直接修改正式檔。將核准候選寫回設定檔後，須重跑 QA 與 check。一般使用者不會看到開發滑桿。

## 驗收與代表字元

自動 QA 包含結構／筆數／筆序、單一連續 SVG 中心線、字框邊界、方向資料、現行短拉帶寫生命週期順向通過、反向與所有其他筆畫錯序拒絕、觸發前取消、自由書寫標準軌跡通過。既有三字回歸測試仍保留。

優先手機／教師人工實測 15 字：`ㅏ、あ、い、き、す、ぬ、ね、の、ふ、も、う、や、ア、ツ、ネ`。涵蓋直線、短筆、相鄰起點、曲線、自交、長回圈、多筆及已知失敗；失敗字元只在開發 QA 排查。

人工步驟：375px 開啟日文→練習→翻答案→切五十音→選字→回練習，確認題目與翻面未變；答一題後切韓文再切回，確認各語言題組獨立。真機核對書寫旋轉、縮放、取消、框外滾動及短拉手感。瀏覽器工具先前受安全政策阻擋，本次未繞過；版面與實際點擊流程不列為已驗證。
