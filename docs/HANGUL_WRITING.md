## 共用流程與實際修正

- 全部韓文字母共用 `src/tracing-engine.mjs`；以共用重採樣、投影、SVG viewBox 及 screen CTM 座標換算，仍使用原動畫播放器與 Pointer Events。沒有逐字判定器或字元特例。
- 舊方向帶寫在前 4% 起拉後就補完整筆，無法確定轉折或圓形真的被描過。韓文改為完整沿線模式：覆蓋／實際行程／沿線比例達標、抵達終點，才補上最後少量並接受。日文原有方向帶寫不改。
- 搜尋限制在目前筆畫、目前進度附近，受筆畫長度與實際手指移動限制；交叉處不做全域最近點搜尋。偏離後可在附近回線，不要求永遠回到單一凍結點。
- 起點與其他筆畫競爭檢查、順序化方向進度、完成時其他筆畫匹配比較，共同拒絕錯序、平行筆誤吸及圓圈倒寫。短筆新增相對長度的輸入跳距限制，避免大半筆跳過後靠後續點補出假進度。
- 短筆終點判定考慮已允許的固定手指偏移，修正「正常輕微偏移卻寫不到終點」；沒有放寬整體容錯。
- 顯示筆跡永遠使用標準中心線；rawPoints 只供驗證，自由書寫保留原始軌跡。SVG clip 限制框內，框內 touch-action:none、框外維持捲動。
- Pointer Cancel／多指／失去捕捉／resize 取消未完成的一筆，保留已完成筆畫。切換查表／測驗時不卸載已開啟書寫；當次頁面以字母 ID 保存快照，回到原字母可接續。已接受但仍在動畫中的筆畫也存入快照。
- 有清除、重試、退回一筆、播放／暫停／重播、下一字母；字母選單在韓文入口只列韓文 40 字。整頁重整不保存書寫快照，不修改既有學習紀錄。

## 集中參數

`data/hangul-settings.json` 為韓文唯一設定來源；動畫 1500ms／筆、接受 450ms，參考線開啟，筆順與反向檢查保持嚴格。

- 起點 15%、磁吸 13%、最大偏移 20%、最低進度／沿線覆蓋 75%、原始行程貼近比例 60%。另有終點條件，僅 75% 並不保證通過。
- 終點距離：8% 字框與 10% 筆長取較小值，允許與起點一致的手指平移。
- 單次移動上限：12% 字框與 25% 筆長取較小值；局部搜尋最多 18% 筆長，轉折／短筆縮為 14%、交叉縮為 12%。
- 方向、逆行累積、進度倍率、起點競爭與其他筆匹配門檻均在同一檔案。字元覆寫為空；有設定驗證，禁止關閉筆順／反向或把完成門檻降至 75% 以下。
- 日文原設定仍在 writing-settings.json。開發預覽可調整現有共用滑桿；韓文的型別／逆向細項以 hangul-settings.json 為準。
