## 1. 產品目標及入口

把一般使用者的書寫體驗收斂成「**引導描寫小關卡**」，以單字帶動字母學習；不做書法評分，不讓每次書寫都面對整個 40／50 音表。

### A. 從單字詳情進入（主要流程）

1. 提供清楚但不搶眼的「練習這個詞」入口；只有具備可信書寫路徑的字母才可練。
2. 開始時依該詞**實際讀音與出現順序**建立 ordered sequence，保留重複字母；每次畫布只載入、顯示**當前的一個基本字母**。
3. 畫布上方只顯示詞語、意思與精簡進度（如 `なに · 1/2` 或 `라면 · 2/5`）；短詞可呈現 2～3 個小字母狀態，長詞採小型進度列，不展示完整 132 字格子、整個語言的下拉選單。
4. 同一字母逐筆引導；最後一筆**放開並驗證成功**後，短促的完成回饋（建議約 0.5～0.9 秒），**自動前進至詞內下一字母**。不需「提交判定」或每字點「下一步」。
5. 全詞完成才顯示「再練一次／返回單字」；若存在明確的既有練習佇列才可提供「下一個單字」，不可擅自跳到隨機字。
6. 可退出／返回；切去查表再回來應恢復該詞當次字母序號與已完成筆畫，避免與獨立字元模式快照相互覆蓋。

### B. 從字母表進入（次要流程）

只練使用者選的那**一個**字母，完成後可重練／返回字母詳情；不再預設自動跳到完整表中的下一字母。完整韓文 40 音表／日文平片假名表保留作**查閱及入口**，而非出現在描寫畫布下方。

## 2. 拆字規則（必須與原有查表用途分離）

- 日文若原文有漢字，採詞庫已記錄的**完整假名讀音**；不能從漢字猜讀音。平假名與片假名保留原字形，依出現順序逐字練習。
- 韓文按 Unicode 音節拆成初聲、母音、終聲，映射至 40 個 compatibility jamo；緊音如 `ㄲ`、複合母音如 `ㅘ` **維持單個已收錄字母**；複合終聲依既有 11 種規則拆成可練的基本子音。需保留所有重複出現。
- 例如 `なに` → `な → に`；`라면` → `ㄹ → ㅏ → ㅁ → ㅕ → ㄴ`；`우동` → `ㅇ → ㅜ → ㄷ → ㅗ → ㅇ`。小卡片可用音節分組，但每步的練習單位仍是基本字母。
- 遇到日文濁音、半濁音、小假名、促音、長音符、韓文標點或現有封鎖字元：**顯示明確原因與已支援的部分**；不可偷偷改成另一個字、當作通過或生成假筆順。若無法完整練該詞，應提示「部分字母尚未開放」，允許返回，不自動宣稱整詞通關。
- 查表標紅仍可繼續使用現在的去重 Set；需新增獨立 ordered sequence/helper 或資料模型，不應修改現有字母篩選語意。

## 3. 互動、按鈕與回饋

- 一般介面僅保留主要的**返回／退出、示範重播（小圖示）、必要時重新練習**；不要同時顯示再練一次、下一個字母、示範/重播、暫停、退回一筆、清除、提交判定等七鍵。
- 正式使用者流程**預設只提供引導描寫**，移除自由書寫切換與「提交判定」；開發診斷功能若有必要，可保留在 DEV/Lab 而不是公開入口。
- Pointer Down：起筆點柔和漣漪／亮起；描寫中：進度沿中心線逐段填色、吸附但不擅自補上未描寫的長段；成功：筆畫短促回彈/柔光；失敗：平靜指出「這一筆需再試」，保留先前完成的筆畫。
- Hover 只作桌面附加提示；手機優先以觸控（含 touchcancel/pointercancel、滑動中斷、多指、縮放）實作。全程避免手指離開線條就無回饋或自動跳錯筆。
- 維持真實筆順、方向、進度與終點檢查，**不要為了動畫而放寬到短拉即通過**。先複用現有判定器，集中調整 UI 及轉場；只有經證據確認判定 bug 才修演算法。
- 動畫不得阻塞觸控或導致完成後重複觸發；背景切換、離頁、重播與取消應安全清除計時器。尊重 `prefers-reduced-motion`，並支援鍵盤焦點、讀屏即時狀態（避免逐點 aria-live 轟炸）。
- 奶茶手帳的 Light / Dark 對比清楚，手機 320/375/390/430 px 無橫向溢出；重要可點擊控件至少 44×44 px。

## 5. 驗收及測試

1. `なに` 從單字詳情開始，只出現 `な` 與 `に` 的順序，寫完 `な` 自動切 `に`，完成後停留在整詞完成畫面。
2. `라면` 五個 Jamo 依序通關；`우동` 最後的重複 `ㅇ` 不被去重。詞庫若不存在這兩詞，測試可使用獨立 fixture。
3. 從字母表選 `ㅏ` 或 `あ`，只練該字元，完成後不跳全語言下一字。
4. 逐筆錯序、反向、短拉、離線回復、Pointer Cancel 不會錯誤完成；錯誤只重試當前筆畫。
5. 已知封鎖 `う／や／ネ`、不支援特殊假名不被默默略過或假裝成功。保留 129/132 及人工未驗的如實標示。
6. 在查表、單字、測驗與書寫間切換時，原查詢、字母篩選、排序、題目、翻卡、書寫進度及 localStorage 保持既有契約；重新整理僅承諾已持久化的資料。
