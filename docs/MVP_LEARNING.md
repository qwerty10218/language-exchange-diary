# MVP 單字、查表與拼字測驗

本次使用者確認的互動優先於交接包舊版「只做翻卡」限制。保留 32 筆日文與 87 筆韓文、既有 Schema、原始記音、Phase 0 書寫及目前技術可用字元；不修改磁吸、判定器或筆順資料。

## 日常操作

1. 預設日文筆記，可切換韓文；首頁已有雨傘等近期詞條，或搜尋「雨傘」。
2. 點詞條主按鈕會切到字母表；展開「讀音、記音與筆記」可看原資料。
3. `かさ` 只標紅 `か／さ`，`すいか` 只標紅 `す／い／か`；紅字、紅框、淡紅底及 ◆ 同時標示。平片假名不互相轉標。
4. 點字母查看讀音、羅馬拼音與書寫狀態。「返回單字」還原來源頁、搜尋、選取與捲動位置；最近查的詞在兩語言分別保留於當次畫面。
5. 「測驗」→「開始測驗」會優先出剛才查看且仍在題庫的詞。中文「雨傘」使用 `か`＋`さ`；刪除上一字可修改，完成所有格後確認。
6. 答錯可直接下一題，或修改再試；同題訂正不再計分，不能靠同題反覆提交取得五連對。查表、語言切換與書寫不卸載兩份測驗，保留題目、未送出的答案、回饋與輪次進度。
7. 韓文提供中文題、韓文音節按鍵及原生鍵盤輸入。40 音表反查依 Unicode 初聲／中聲／終聲拆解，複合收音拆成基本子音；不是把整個音節當一個字母。

## 假名與題庫界線

- 以 NFC 及 grapheme 分段解析，重複假名只標一次；不將濁音、小促音、小拗音或長音錯標成基本假名。未收錄字元原樣顯示於「基本表未收錄」。漢字詞只用詞庫已提供的 reading，不猜讀音。
- 完整 46 平假名與 46 片假名依 a/i/u/e/o 對齊，や／わ 行保留空格。測驗另提供濁音、半濁音、小假名、ー 按鍵；一格一字元，不是一格一拍。
- 拼字僅讀正式詞庫；題意從既有中文欄位拆出。相同中文對應不同拼字時不採該提示，無其他唯一提示者暫不出題；不從備註自行猜同義答案。
- 本版日文 29 個可出題詞、3 個中文題意重疊而排除；韓文 70 個可出題詞，其餘含文法、粗口、縮寫、標點句或題意重疊者暫不出題。排除原因可在測驗頁查看，原詞庫均保留。
- 全部詞條仍為 needs_review。真人語音未收錄；書寫缺資料／技術失敗狀態沿用，不冒充人工驗證。

## 學習紀錄與出題

- 新鍵：`language-exchange-diary:learning:v2`，格式 `{version:2,records:{[entryId]:record}}`。
- 每筆保存 correct、wrong、streak、lastPracticed、nextReview、state；狀態包括 new／practicing／mastered／due，顯示時依目前時間更新到期狀態。
- 連對間隔 1／3／7／14／30 天；五連對退出一般池，到期可在「到期複習」出現。複習錯誤歸零連對，保留累積正誤，重新加入一般池。
- 錯題權重較高，且不連續出同一 ID；只剩一個可用詞時不立即重複，本輪提早結束。新詞正常出題，不要求先修字母課。
- 舊 `language-exchange-diary:review:v1` 完整保留，不刪除、不改寫；舊自評移入 legacyReview 提示，不虛構拼字正確次數。原翻卡元件與 v1 儲存方式仍可使用。
- 載入損壞或未來版本時禁止覆寫；未知但合法的舊詞條 ID 保留。配額／權限失敗明示，本輪仍可在記憶體作答。
- 整頁重新整理保留已儲存的學習紀錄，但會結束未完成題組。相同裝置不同來源網址（localhost／LAN／正式域名）有獨立 localStorage，不會自動遷移或同步給朋友。

## 驗證與手機人工驗收

- `npm run check`：資料與書寫 QA、TypeScript、196 項 Node 測試、production build。
- 自動測試包含五組詞連動、Unicode／大小假名／平片字形、韓文收音拆解、實際 React SSR 標紅格數、雨傘作答、刪字／錯誤／訂正、加權、五連對與到期、語言隔離、v1 遷移、v2 重新載入及失敗保護。
- SSR 與純邏輯測試不等同瀏覽器實際點擊或版面量測。瀏覽器工具先前被安全政策阻擋，本次不繞過；375px、320px、實際 Safari 觸控與無橫向溢出仍需人工驗收。
- 手機重點：搜尋雨傘→點かさ→確認僅か／さ標紅→返回原詞→測驗か＋さ；在只輸入か時查表再返回；答錯後訂正與下一題；重新整理確認統計保留；日韓互切確認各自題組不變。
- 再測長詞、濁音與小假名、橫向畫面、鍵盤升起；確認黏住的答案卡不遮住字母按鍵，框外能正常捲動。

## 本機與未來分享

- 本機：`npm ci` 後 `npm run dev`；正式產物本機檢查為 `npm run build`、`npm run preview`。
- 區網：`npm run dev -- --host 0.0.0.0 --port 5173 --strictPort`，手機與 Windows 同一 Wi-Fi，開 `http://<電腦區網IP>:5173/`。不是公開網址；未修改防火牆、建立隧道或部署。
- 建議先用獨立根網址的 HTTPS 靜態託管發布 `dist/`，無須帳號系統或後端；可考慮 Cloudflare Pages。Build 使用 `npm run check`，輸出目錄 `dist`。參考 [Vite 官方靜態部署指南](https://vite.dev/guide/static-deploy.html)。
- 若選 GitHub Pages 的 `/language-exchange-diary/` 子路徑，部署前須設定對應 Vite base 並重新驗收靜態素材連結；目前沒有加入自動發布 workflow。
- 換正式網址時，本機／LAN 練習紀錄不會自動帶入。正式詞庫更新需改專案 JSON、驗證後取得使用者明確指示才發布；先核對內容適合公開。

主要程式：`src/MvpApp.tsx`、`Alphabet.tsx`、`Quiz.tsx`、`word-letters.mjs`、`quiz-model.mjs`、`study-types.ts`、`mvp.css`；測試 `tests/quiz.test.mjs`、`learning-ui.test.mjs`。未新增依賴、登入、後端或付費服務。
