# UI 設計 — 奶茶手帳（手機優先）

## 視覺語言
- 奶茶背景 `#F4ECE0`；卡片 `#FFFBF5`；深棕字 `#43352F`；次級字 `#79685C`；焦糖主色 `#AE785A`；柔和綠輔色 `#798B78`；分隔線 `#E4D8CC`。
- 圓角 14–18px、輕邊框、細緻留白；禁止重度仿紙材質和大面積噪點背景。
- 選用易讀的中日韓字型；日文需正確設定 `lang=ja`、韓文 `lang=ko` 避免 CJK 漢字形體混亂。
- 正文對比度必須足夠；觸控目標建議至少 44×44 CSS px；動畫可設定減少動態效果。

## 手機資訊層級
```
[ 言語交換日記                   ▤ ]
[ 🇰🇷 朋友教我的韓文 | 🇯🇵 我教的日文 ]
[ 🔎 搜尋文字、意思、個人記音... ]
[ 開始複習           ] [ 練習寫字 ]
  最近新增
  ┌──────────────────────────┐
  │ 다이어트             減肥 │
  └──────────────────────────┘
  ┌──────────────────────────┐
  │ 소고기               牛肉 │
  └──────────────────────────┘
[ 筆記       複習       書寫 ]  ← 手機底部導覽
```

- 選擇語言後在詞庫與複習沿用；從書寫頁返回時應保留先前查詢。
- 卡片點開顯示例句與備註（如有），真人錄音用一個明顯的播放鍵；無音檔用「尚無真人錄音」，不能顯示空按鈕。
- 「我教的日文」包括假名、漢字振假名；韓文自訂記音作為輔助資訊，與標準羅馬拼音分開。
- 手機書寫頁：大正方形字框、田字格/十字輔助線、筆畫編號和方向、播放/暫停/重播/清除/提交。僅書寫畫布設 touch-action:none；外圍正常捲動。
- PC：單欄置中可先完成；若擴展，左側詞條、右側詳情；不要求複雜儀表板。

## 互動狀態
- 搜尋：空白→最近詞條；無結果→顯示友善空狀態；大小寫與空白正規化；日韓查詢只查本分頁。
- 複習：顯示答案前不暴露答案；答後可標「再學習／有點印象／記住了」，儲存本機。
- 書寫：看動畫→跟寫→自由寫；判定顯示例如「第二筆方向不一致」而非單純紅叉。
- 音訊：有檔/載入中/播放中/失敗/缺音檔四個狀態。

## 無障礙與效能
支援鍵盤操作、語意標籤和焦點可見；按鈕不是只有顏色區分；懶載音檔與筆順 SVG；在 375px 寬視窗測試版面。
