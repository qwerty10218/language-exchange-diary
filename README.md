## MVP 本機執行
- `npm ci`、`npm run dev`：開啟本機原型；沒有後端、登入或線上內容編輯。
- `npm run check`：資料驗證、TypeScript、幾何／資料測試與 production build。
- `npm run validate:data -- --preview ko <JSON檔案>`（或 `ja`）：只檢查離線匯入候選，不寫檔、不儲存瀏覽器資料，也不會同步給朋友。
- 正式更新須由維護者檢視差異與衝突後修改 `data/ko.entries.json` 或 `data/ja.entries.json`，通過檢查並取得部署指示後發布，朋友重整才讀到新版；Phase 0 不提供正式匯入器。
- `data/phase0.audio-candidates.json` 記錄各語言五條音訊調查；沒有可播放音檔，所有候選待人工檢聽與授權覆核。詳見 `docs/AUDIO_SOURCES.md`。
- `data/phase0.strokes.json` 只含三字原型中心線；原始 SVG、來源版本及授權隨附於 `public/strokes/sources/`。目前中心線與容錯待人工及手機真機確認。

## 一句話定位
一個可分享網址、無須登入的日韓語言交換手帳：兩份獨立筆記、查詞、複習、真人發音，以及可在手機上跟著筆順描寫的韓文 40 字母和日文基本假名。

## 最終決策（不得擅自改回舊版）
- **不需要帳號、後端資料庫、多人權限、即時協作或管理員介面。**
- 網站公開網址供朋友觀看／練習；由專案擁有者更新 Git 內的內容檔並重新部署。
- 日記感來自單字、例句、備註和奶茶色視覺；不建立聊天時間軸、私訊同步或私人對話紀錄。
- 韓文（朋友教我）與日文（我教朋友）完全分區，支援查詢、翻卡與簡易練習。
- 書寫包含筆順動畫、引導描寫、筆畫序列／方向／近似軌跡判定；手機觸控優先。
- 書寫範圍：韓文 **19 子音＋21 母音**，日文 **平假名 46＋片假名 46**。日文漢字不做筆順，僅標假名、詞義及有授權的真人音檔。
- **不把合成語音冒充真人錄音。** 未驗證真人語音時顯示「尚無錄音」；不得假造檔名或音訊來源。
- 先在 ChatGPT 討論設計，**Codex 負責執行程式工作**；Codex Plan Mode 只跑 1 次、至多補 1 次修正。

## 單字連動與拼字測驗（本次 MVP）
- 點日文單字自動查五十音，精確標紅原字形；基本表以外的小假名、濁音與長音原樣列出。返回單字保留搜尋、選取及捲動位置。
- 測驗看中文、點假名拼字，支援刪除、訂正、查表不中斷；韓文使用音節按鍵或鍵盤。原翻卡保留在次要入口。
- 保存逐詞正誤／連對／練習與複習時間；五連對暫退一般池，錯題加權且不連續重複，提供到期複習與統計。
- v2 學習紀錄不刪除舊 v1 翻卡資料；自評不算拼字答對。損壞／未來版本停止覆寫；無法儲存會提示。
- 詳細規格、測試、手機驗收與分享建議見 [MVP_LEARNING](docs/MVP_LEARNING.md)。當次題組在切頁時保留；整頁重整只還原已儲存紀錄。

# 讀音朗讀與逐筆描寫更新

- 詞條的「讀音、記音與筆記」、字母詳情、書寫頁與測驗提交後提供裝置合成朗讀，非真人錄音。日文優先使用詞庫假名，韓文使用原文；韓文子音朗讀字母名稱，不假充音節中的實際發音。
- 可選裝置聲音與自然／慢速；優先選擇同語言的 enhanced／premium／natural 聲音，未安裝日／韓語音時明示不可用，不退回英文。不同裝置的自然程度與連網需求不同，iPhone Safari 聲音品質尚待人工驗收。
- 日韓引導書寫一律放開後判定，每筆至少 75% 沿線進度與足夠實際移動。取消日文短拉觸發自動補完；歷史方向帶寫 API 保留供舊測試與資料檢查，日常書寫頁不使用此捷徑。
- 書寫來源、真人音檔與詞庫 Schema 未變；合成語音不會寫入 `audio` 欄位。新增內容需依既有發布流程更新後，才會出現在朋友使用的公開網站。
