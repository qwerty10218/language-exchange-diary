# 字母與文法複習備忘（非新增詞條）

本頁整理在先前對話中解釋過的規則與例詞，不代表朋友逐一教過。避免把「教學補充」全部混入正式互教詞庫。

## 韓文組字與收音

- 一個音節可由初聲＋中聲（母音）＋終聲（收音）構成，如 `밥 = ㅂ + ㅏ + ㅂ`。
- `고 = ㄱ + ㅗ`，`기 = ㄱ + ㅣ`。`고기`、`소고기` 適合拿來拆字。
- `은/는` 主題助詞：有收音用 은，無收音用 는；`을/를` 受詞助詞同理。
- `의（ㅢ）` 在不同詞位可能有不同讀法；`의사`、`이사` 適合聽辨；「의」不等於單獨的「이」。
- 發音變化範例：`밥을` 常讀 `[바블]`；`먹어요` 常讀 `[머거요]`；`입니다` 讀 `[임니다]`；`집밥` 常讀 `[집빱]`。
- `(으)ㄹ래요` 可以表達意願或詢問，例如 `마실래요`、`먹을래요`。

## 日文假名從單字遷移

建議學習鏈：`すし → すいか → しお → かさ → いぬ → しけん`。

- `すし`：す、し。
- `すいか`：複習す，新認い、か。
- `しお`：複習し，新認お。
- `かさ`：複習か，新認さ。
- `いぬ`：複習い，新認ぬ。
- `しけん`：複習し，新認け、ん。

日文 `つ` 常見平文式 `tsu`，輸入法可用 `tu`；日文 `う` 與中文「屋」的圓唇方式不同。這是讀音教學備註，不是額外新增字彙。
