# MVP 範圍（本次優先，與舊「完整 v1.0」不同）

## 使用者新決定

**先讓網站變得好用，優先把已學的單字上站。** 不讓筆順、真人錄音或 132 字完整度阻擋 MVP。

1. 靜態 Vite + React + TypeScript，無登入、後端或資料庫。
2. 奶茶手帳視覺，手機可用、中文介面。
3. 兩個獨立 Tab：`ja` 我教朋友的日文、`ko` 朋友教我的韓文。
4. 最基本的詞條卡片：原文、意思、日文假名、標準羅馬字、朋友原始記音、備註。
5. 可搜尋：原文、中文、記音／讀音及備註；可選只看某語言。
6. 複習：最簡單的「看字猜意思 → 點開答案 → 記得／忘記」，存在各自裝置 localStorage。
7. 既有 Phase 0 的 ㅏ／あ／ア 書寫原型**保留**；可放獨立入口或現有頁面，不在本次改寫判定器。
8. 真人錄音欄位先顯示「尚未收錄」或不顯示播放器；不造音檔、不假裝 TTS 是真人。
9. 原詞庫 JSON 維護方式不變。網頁不用加入 JSON 編輯 UI。
10. 本次新增的日韓筆記使用 `data/*.entries.json` 格式，以原有 `schemas/entry.schema.json` 為準。

## MVP 明確不做

- 登入、帳號、雲端同步、Supabase、公開編輯頁。
- 132 字筆順擴充、磁吸判定重寫、全套真人發音收集。
- 每日打卡、積分、排行榜、日記時間軸、多語系切換、AI 自動聊天分析。
- 為了匯入這份包而重建整個 Repo 或重置既有工作。

## 完成標準

- 使用者開啟網頁就能找到完整且分開的日韓詞條。
- 手機上搜尋「소고기」「牛肉」「試験」「しけん」「Shi hom」有符合預期的結果。
- 點一筆能展開意思與補充資訊；不會把朋友個人記音顯示為標準發音。
- 翻卡／記得／忘記可以使用；重新整理後本機進度保留。
- Phase 0 書寫入口仍可用，舊測試沒有倒退。
- `typecheck`、現有測試和 `build` 都通過，資料可通過既有 Schema。
- 無自行 commit、push、部署。
