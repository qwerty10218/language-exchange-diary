# Codex Run：按階段執行

請先讀根目錄 `AGENTS.md` 及 `docs/BUILD_ROADMAP.md`，遵守已核准的 Plan Mode 計畫。**本次只實作 Phase 0（技術可行性原型）**，不要一次完成整站。

具體要求：
- 初始化最小可運行前端（Vite + React + TypeScript），只用必要依賴。
- 做 `ㅏ`、`あ`、`ア` 的手機適用字框、示範動畫、跟寫、自由寫和初步判定；不得以字型輪廓假裝逐筆中心線。若素材無合法可用路徑，做清楚的阻礙記錄，不偽造。
- 語音部分只建立 `human_recording` 的資料流程和可檢驗來源欄位；第三方音檔取得／授權未核實前不得直接填入，也不得用 TTS 取代。
- 以手機 Safari 為主要相容目標，支援 Pointer Events，處理 touch-action、取消事件和畫布座標。
- 只做此階段必要的簡短測試。結束時輸出：變更檔案、執行的測試、功能結果、阻礙、下一階段建議（總計不超過 12 行）。
- 不 Commit、不 Push、不部署，除非維護者明確指示。

Phase 0 驗收後，維護者可把本提示第一行的「Phase 0」改成「Phase 1」等，並按 `docs/BUILD_ROADMAP.md` 的該階段範圍指派實作，避免反覆要求重新規劃。
